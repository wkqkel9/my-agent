# Lesson 6 — 판단의 흐름: LangGraph와 SQLite 세이브·사람 승인

수업 자료: [나니아랩 PBL 06](https://narnialab.duckdns.org:18231/session-06.html)

## 무엇을 배우고, 왜 배우는가

수업의 목표는 단순한 1회성 함수 호출을 넘어, 상태(State)를 중심으로 노드(작업 단위)와 엣지(조건부 갈림길)로 연결된 복잡한 에이전트 작업 흐름을 LangGraph로 구성하고, SQLite 체크포인터를 통해 대화 세션별 상태를 영구 저장하며, 민감한 결정 직전에 사람의 승인을 받아 안전하게 진행하는 워크플로를 구축하는 것이다.

이 수업을 거쳐 최종적으로 나오는 완성 결과물은 **‘사용자의 한 줄 요청에 맞춰 대화·검색·문서·도구 중 알맞은 경로로 상태를 전이시키며 작업을 수행하고, 프로그램을 재시작해도 세션(`thread_id`)별 진행 상태를 복원하며, 중요 행동 전 사람의 승인을 거쳐 실행하는 상태 기반 제어 에이전트 시스템(`flow.py`)’**이다.

| 배우는 내용 | 배우는 이유 | 최종 결과물에서의 역할 |
|---|---|---|
| LangGraph 상태 (State) 및 노드/엣지 정의 | 작업 간에 공유되는 메모장(상태)을 정의하고, 각 작업을 노드로 분리하여 명확한 실행 흐름을 구성한다. | 에이전트의 전체 작업 흐름 뼈대 및 데이터 전달 |
| 조건부 갈림길 (Conditional Edge) | 입력 문맥이나 이전 작업 결과에 따라 검색, 계산, 종료 등 다음으로 이동할 노드를 동적으로 결정한다. | 적절한 전문 부품(대화·검색·문서·도구) 라우팅 |
| 종료 조건 및 반복 한도 (Recursion Limit) | 무한 루프에 빠지지 않도록 안전하게 완료 조건을 두고 최대 실행 횟수를 제한한다. | 안전한 시스템 운영 및 자원 낭비 방지 |
| SQLite 체크포인터 (영구 세이브) | 메모리에만 머무는 상태를 데이터베이스 파일에 자동 저장해 프로그램 종료 후에도 동일한 `thread_id`로 작업을 재개한다. | 세션별 멀티 세이브 슬롯 및 이어서 하기 지원 |
| 사람 승인 (Human-in-the-loop Interrupt) | 결과를 확정하거나 변경하는 노드 직전에 실행을 일시 정지하고 사람에게 승인(`y/n`)을 요청한다. | 위험 작업 전 최종 통제권 확보 |

수업의 기본 흐름은 다음과 같다.

```text
사용자 입력 ──→ 상태(State) 생성 (thread_id 지정)
                      │
                      ↓
              [라우터 노드: 조건부 갈림길]
             ┌────────┬────────┴────────┬────────┐
             ↓        ↓                 ↓        ↓
          일반대화  자료검색          문서검색  도구계산
             └────────┴────────┬────────┴────────┘
                               │
                               ↓
                      [사람 승인 노드 (Interrupt)]
                        ├── 승인(y): 최종 결과 확정 및 DB 저장
                        └── 거절(n): 작업 취소 또는 이전 분기로 복귀
```

최종 결과물은 여러 도구와 지식 부품들을 하나로 엮어 상황에 맞게 유연하게 경로를 선택하고, 과거의 작업 상태를 온전히 보존하며, 최종 판단 단계에서 사람의 개입을 안전하게 보장하는 통합 워크플로 엔진으로 완성된다.

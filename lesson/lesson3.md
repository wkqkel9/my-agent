# Lesson 3 — 지식 ①: 뜻으로 찾기와 작은 RAG

수업 자료: [나니아랩 PBL 03](https://narnialab.duckdns.org:18231/session-03.html)

## 무엇을 배우고, 왜 배우는가

수업의 목표는 사용자가 입력한 일상 언어의 문장을 숫자 벡터(임베딩)로 변환하고, 저장된 자료들과 코사인 유사도로 비교하여 가장 관련 있는 상위 자료를 찾아낸 뒤, 그 자료를 질문에 끼워 신뢰할 수 있는 답을 생성하는 RAG(검색 증강 생성)의 기본 뼈대를 이해하고 구현하는 것이다.

이 수업을 거쳐 최종적으로 나오는 완성 결과물은 **‘키워드가 일치하지 않아도 문장의 뜻(의미적 유사도)을 기반으로 관련 자료를 상위 k개 찾아내고, 찾아낸 원문 자료를 질문에 함께 끼워 근거 기반의 정확한 답변을 생성하는 검색 증강 질의응답 프로그램(`search.py`)’**이다.

| 배우는 내용 | 배우는 이유 | 최종 결과물에서의 역할 |
|---|---|---|
| 임베딩 (Embedding) | 글의 뜻을 다차원 숫자 목록(벡터)으로 바꾸어 컴퓨터가 의미를 수치적으로 비교할 수 있게 한다. | 질문과 저장된 자료 문장들을 벡터로 변환 |
| 코사인 유사도 (Cosine Similarity) | 두 벡터가 가리키는 방향의 유사도를 측정해 글자 일치 여부와 무관하게 뜻의 가까움을 계산한다. | 질문 벡터와 각 자료 벡터 간의 의미 유사도 점수 계산 |
| 상위 k개 정렬 (Top-k Ranking) | 계산된 점수를 기준으로 정렬하여 가장 연관성이 높은 핵심 자료만 추려낸다. | 질문과 가장 가까운 상위 k개 자료 선별 |
| 로컬 임베딩 모델 실행 | 외부 API 호출 없이 로컬 PC(환경)에서 직접 임베딩을 계산하여 비용과 지연 시간을 줄인다. | 오프라인·로컬 벡터 변환 연산 수행 |
| RAG (검색 증강 생성) 프롬프트 조립 | 모델의 기억에만 의존하지 않고 찾아낸 실제 원문 자료를 질문에 보태어 할루시네이션(거짓 정보)을 방지한다. | 찾은 자료와 질문을 하나의 프롬프트로 묶어 답변 생성 모델에 전달 |

수업의 기본 흐름은 다음과 같다.

```text
내 자료들 ─────────→ 로컬 임베딩 모델 ───→ 자료 벡터 목록
                                             │
사용자 질문 ───────→ 로컬 임베딩 모델 ───→ 질문 벡터
                                             │
                                   [코사인 유사도 비교]
                                             │
                                   상위 k개 관련 자료 선별
                                             │
                          질문 + 찾은 자료 원문 결합 (RAG 프롬프트)
                                             │
                                   근거 기반 최종 답변
```

최종 결과물은 단순히 글자가 일치하는 줄을 찾는 키워드 검색(`keyword.py`)과 달리, 다른 표현으로 질문하더라도 의미상 가장 가까운 원문과 점수를 출력하고 그 자료에 근거한 정확한 답변을 생성한다.

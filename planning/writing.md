# 영작

## 대미션

학습자에게 좋은 영어 문장을 제공하고, 단계적·반복적으로 직접 영작하게 하여 체화시킨다.

## 세부 미션 1. 좋은 문장을 제공한다

좋은 문장은 현재 수준에 맞고, 실제 영어로 자연스러우며, 선택한 주제와 상황에 적합하고, 학습자의 취약한 부분을 보완하는 문장이다.

| 판단 대상 | 기준 |
|---|---|
| 난이도 | CEFR `A2`·`B1`·`B2`·`C1` |
| 문법·구문 | English Grammar Profile(EGP) |
| 어휘·연어 | English Vocabulary Profile(EVP) |
| 주제·상황 | 해당 분야의 실제 사용 상황과 공신력 있는 자료 |
| 개인 적합성 | 학습 요소별 오답·시간 종료 누적 기록 |

- 사용자는 `토익`·`기사`·`책(문학)`·`영어 인터뷰` 중 주제와 CEFR 난이도만 선택한다. 초기 고도화는 영어 인터뷰를 우선한다.
- 원문은 복제하지 않는다. 자료에서 주제·상황·문체·학습 요소를 분석한 뒤 독립적인 문제로 제작한다.
- 문법·구문·어휘·문장 기능은 내부 `학습 요소`로 태깅한다. 사용자가 직접 고르는 별도 집중학습 모드는 두지 않고, 취약 요소가 포함된 문제의 출제 비중을 높인다.
- 외부 기준이 있는 항목은 해당 기준을 따른다. 외부 기준이 없는 항목은 구현 전에 판정 조건과 자동 검증 방법을 정의하고, 검증을 통과한 문제만 문제은행에 등록한다.

## 세부 미션 2. 문장을 단계적으로 확장한다

한 문제를 4단계로 확장한다. 각 단계는 완전하고 자연스러운 문장이면서 이전 단계의 의미를 유지하고, 주요 의미 단위 하나를 더해야 한다. 단계가 바뀔 때 문장 전체를 불필요하게 다시 쓰게 하지 않는다.

Sentence combining은 확장 원리로 참고하고, 4단계 구성은 위 조건을 만족하도록 이 서비스의 문제 제작 규칙으로 운영한다.

## 세부 미션 3. 각 단계를 제한 시간 안에 완성하게 한다

단계마다 제한 시간은 60초다.

| 결과 | 동작 | 학습 기록 |
|---|---|---|
| 정답 | 즉시 다음 단계로 이동 | 정답 기록 |
| 오답 | 가장 우선하는 오류 하나를 안내하고 재시도 | 해당 학습 요소의 오답 기록 |
| 시간 종료 | 해당 단계의 대표 답안 하나를 보여주고 다음 단계로 이동 | 해당 학습 요소의 시간 종료 기록 |

- 등록된 허용 답안은 브라우저에서 즉시 통과시키고, 그 외 답안은 AI가 필수 의미·불필요한 의미·문법·어휘를 판정한다.
- 대표 답안은 가능한 여러 정답 중 하나이며 유일한 정답을 뜻하지 않는다.
- 제한 시간 안의 피드백에는 정답 문장·교정문·예시 답안을 노출하지 않고, 문제가 있는 부분·이유·수정 방향만 안내한다.
- 한 번에 오류 하나만 안내하며 우선순위는 `불필요한 표현` → `틀린 표현·철자` → `빠진 표현`이다.
- 오답과 시간 종료 기록은 세부 미션 1의 취약 요소별 출제 비중에 반영한다.

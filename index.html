How it works

기능과 동작 방식

한글 상황을 영어로 써 보고, 피드백을 받아 다음 문제에 적용합니다. 연습 문제를 만들고, 챗봇의 요청을 처리하고, 내 기록에서 복습할 표현을 찾는 데 각각 다른 기술을 사용합니다.

실전 영작과 AI 교정

  • 사용 기술 · JavaScript setInterval(), Python HTTP API, Groq·OpenAI Chat Completions API
  • 서버가 핵심 표현과 난이도를 고르면 AI가 한글 상황과 모범 답안을 만듭니다. 입력창을 누르면 60초 타이머가 시작됩니다.
  • 답안을 제출하면 AI가 의미, 문법, 자연스러움을 평가합니다. 정답·부분 정답·오답과 함께 교정문과 수정 이유를 볼 수 있습니다.

챗봇으로 연습 조절

  • 사용 기술 · Function Calling, JSON Schema, Python 인수 검증
  • “난이도 B2로 바꿔 줘”라고 하면 AI가 설정 변경 함수와 B2라는 값을 고릅니다. 서버가 허용된 함수와 값인지 확인하면 웹앱이 적용합니다.
  • “다른 문제로 바꿔 줘”, “오답노트로 연습해 줘”, “훈련 종료”도 같은 방식으로 처리합니다. 기능 사용법을 물으면 안내를 보여줍니다.

약한 표현 맞춤 복습

  • 사용 기술 · LangGraph StateGraph, interrupt(), Command(resume=...)
  • 로그인 후 “내가 약한 표현 연습시켜 줘”라고 하면 최근 30회 안의 오답과 부분 정답을 모아 어떤 표현을 복습할지, 왜 추천하는지 보여줍니다.
  • LangGraph는 계획을 기억한 채 답을 기다립니다. “시작”하면 같은 표현으로 새 상황 3개를 풀고 세트 결과를 봅니다. “취소”하면 풀던 문제를 이어갑니다.

자동 난이도와 복습 간격

  • 사용 기술 · Python 조건 분기, datetime, Supabase REST API
  • 로그인한 사용자의 채점 결과를 반영해 CEFR 기준으로 기본 난이도를 조절합니다. 틀린 표현은 비교적 일찍 다시 나오고, 익숙해진 표현은 간격을 두고 복습합니다.

개인 학습 기록과 분석

  • 사용 기술 · Supabase Auth, PostgreSQL, 행 단위 접근 제어(RLS)
  • 로그인하면 채점 결과와 표현별 진도가 계정에 저장됩니다. 학습 기록에서 이전 답안과 교정문을 다시 보고, 학습 분석에서 정답률과 자주 놓치는 표현을 확인합니다.
  • 행 단위 접근 제어는 로그인한 사용자가 자신의 기록에만 접근할 수 있도록 합니다.

FAQ와 문법 자료 찾기

  • 사용 기술 · Python 키워드 매칭, BM25, difflib.SequenceMatcher
  • 이용 방법 질문은 등록된 키워드에 맞는 FAQ를 보여줍니다. 문법 자료 찾기는 질문과 표현이 가까운 자료 세 줄을 뽑아 관련도 점수와 함께 보여줍니다.
  • 찾은 자료는 질문과 함께 묶어, AI에게 근거를 주고 물어볼 수 있는 프롬프트로도 제공합니다.
